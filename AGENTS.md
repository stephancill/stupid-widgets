# AGENTS.md

## Project

A better, API-compatible alternative to Scriptable (iOS JavaScript automation app).
iOS app first, using xtool/SwiftUI with a JavaScriptCore bridge.

## Ground rules

- **Read the planning docs before changing anything:**
  - `docs/engineering-handover.md` — current implementation status, runbooks, risks, and takeover plan.
  - `docs/scriptable-architecture.md` — architecture inventory + gap analysis + AI design.
  - `docs/implementation-notes.md` — log of changes; update it before committing.
- **API compatibility contract:** `docs/scriptable-api.json` (generated by
  `tools/generate-api-spec.mjs`) defines the JS bridge surface (types, members, signatures) and
  generates the agent's bundled `Resources/scriptable-api.json` lookup data.
  Run `bun run tools/generate-api-spec.mjs` after any extraction changes.
- **The Scriptable bundle is gitignored** (`third-party/`). Inspect it there; never commit it.

## Tech stack

- iOS app: **xtool**, **SwiftUI**, **JavaScriptCore** for the JS runtime.
- AI: client-side ChatGPT device OAuth, iOS Keychain Services, and direct Codex Responses SSE.
- There is no AI backend or deployable web service in this repository.
- Tooling: **bun** is used only for API extraction scripts.
- Editor conventions: no comments unless requested; prefer named parameters for non-framework APIs.

## Workflow

1. Check `docs/` planning + implementation notes before changes.
2. Make changes; lint/format (project tooling if present, else oxlint/oxfmt).
3. Update `docs/implementation-notes.md` documenting what changed and why.
4. Commit with conventional commits (`fix:`, `feat:`, `chore:`...).
5. Before archiving or uploading a release, increment `CFBundleVersion` in both
   `stupid-widgets/Info.plist` and `stupid-widgets/WidgetExtension-Info.plist` to the same value.
6. After making app-affecting changes, always build, run the simulator tests, and deploy to the
   iPhone via: `stupid-app run --usb --sudo /usr/bin/sudo --udid 00008130-001C4CA030A1401C`.
7. Domain: widgets are `.widget` files; the only bundled resource is `Resources/scriptable-api.json`.
